# Bharat Bazaar Intelligence Platform

## Project Overview
Bharat Bazaar Intelligence Platform is an end-to-end Data Analytics project built to analyze global e-commerce sales data. The project demonstrates the complete analytics lifecycle, from data cleaning and SQL analysis to machine learning and interactive Power BI dashboards.

## Objectives
- Analyze sales performance across different countries and regions.
- Identify top-performing products and customer segments.
- Predict sales trends using Machine Learning.
- Generate business insights for better decision-making.

## Tech Stack
- Python
- Pandas
- NumPy
- SQL (SQLite)
- Scikit-learn
- Power BI
- Jupyter Notebook
- Git & GitHub
